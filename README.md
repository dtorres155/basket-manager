# Basket Manager 2026-27

Juego de gestión de baloncesto en un único `index.html` (móvil, 3D con Three.js r128). Modos: presidente, director técnico, entrenador y carrera de jugador (desde cadete, universidad o liga europea).

```
npm install
npm test           # build + 26 pruebas
npm run build      # genera index.html
npm run serve      # http://localhost:8080
```

Empieza por `CLAUDE.md`. Documentación en `docs/`. El `index.html` incluido es la versión publicada como prototipo.
